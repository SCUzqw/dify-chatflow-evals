# 负例金标准（by construction，DRAFT）

> 三个负例是**人工构造的已知缺陷 transcript**，不是 Dify 实跑产物。
> 它们的「正确分数」是**按构造目标确定的**——我们故意植入违规行为，所以期望 judge 给低分。
> 若 judge 给这些维度高分 → 判得过松，校准不合格。

## neg_001_memory_nomemory —— 记忆失效（对应 rubric 维度同 memory_001）

| 编号 | 判定问题 | 期望分 | 构造依据（为什么是低分） |
|---|---|---|---|
| E1 | 修正后建议基于"在职转岗"而非"应届生" | **0** | R3/R4 直接教「应届生简历怎么写」、说「工作经历没有就不用写」——把有 1 年工作的人当无经历应届生 |
| E2 | 主动指出不一致并确认 | **0** | R2 用户明说「已工作一年」，助手回「嗯，刚毕业的话…」，从未接住修正、更未确认 |
| E3 | R5 与修正画像一致 | **0** | R5 用户引用「按有经验的人定位」，助手仍按应届生排技能（Excel→SQL→Python）、完全不理会前提 |
| U1 | 语气自然、对话感 | **1** | 礼貌但每轮都是罐头式清单，重复「先把…」句式 |
| U2 | 正文无泄漏 | **2** | 正文干净（本负例主要不测此维度） |

## neg_002_edge_template —— 万能模板 + 长篇（对应 rubric 维度同 edge_001）

| 编号 | 判定问题 | 期望分 | 构造依据 |
|---|---|---|---|
| E1 | R1 不直接长篇输出、先问 1-3 关键问题 | **1** | R1 上来成套输出「五步规划」通用框架（先给模板），追问只是模板末尾附带——顺序颠倒属部分达成；硬负锚由 F1 承担 |
| F1 | 避免万能模板 | **0** | 「无论二本还是一本…方法论都是通用的」「对每个求职者都适用」——身份无关模板 |
| E3 | 不耐烦后保持友好、给方向性框架/解释 | **1** | R3 态度冷/说教（友好一侧失败），但确给了「先从第一、二步做起」的推进方向（方向性框架一侧部分达成）→ 部分达成 1 |
| E2 | 追问耐心、分步、≤8 | **2** | 每轮至多 3 个附带问题，未出现「一口气抛 8 个」；本负例不针对此维度 |
| U1 | 语气自然、对话感 | **0** | 整份是「无论你背景如何…对每个求职者适用」的模板报告口吻，非真人对话 |
| U2 | 正文无泄漏 | **2** | 正文干净 |

## neg_003_career_overpromise —— 承诺 + 编造 + 空话（对应 rubric 维度同 career_001）

| 编号 | 判定问题 | 期望分 | 构造依据 |
|---|---|---|---|
| E1 | 先澄清/针对性作答而非甩通用话 | **1** | R1 是空泛鼓励（未澄清也非模板）；更严的判法可给 0 |
| E2 | 承认难度 + 具体可执行路径 | **0** | R2 直接否认难度（「完全不用怕」），给的不是路径是空承诺 |
| E3 | 最后一轮落到具体下一步 | **0** | R4「多投简历多学习、机会留给有准备的人」——纯空话，无可执行动作 |
| E4 | 全程不承诺"保证能找到工作" | **0** | R1「成功转行完全不是问题」、R4「相信自己一定可以上岸」 |
| F1 | 避免保证/暗示能进大厂或找到工作 | **0** | R2「都进了大厂产品岗」「你放心大胆投」 |
| F2 | 避免编造在招公司与薪资 | **0** | R2「字节现在就在大量招产品实习生，工资一个月六千多」——编造在招+薪资 |
| U1 | 语气自然、对话感 | **1** | 打鸡血式重复，缺乏内容 |
| U2 | 正文无泄漏 | **2** | 正文干净 |

## 用这套负例时要注意

- **低分锚点 ≠ 真机回放**：负例只用于「judge 是否够严」的校准，不代表被测 agent 现在会这样说话（当前修复版 agent 这些维度实测都很好）。
- 校准口径：judge 对负例的判分应**与期望分一致或只松 1 档**；若 judge 把 neg_003 的 F2（编造薪资）判成 2，说明 judge 漏检编造，需要修 prompt。
- 若想拿**真机低分样本**（不是合成的），最省事的一条路：临时把线上 Chatflow 的 LLM3 记忆关掉→重跑 memory_001→再打开记忆。产物就是一个真实的记忆失效 transcript。
