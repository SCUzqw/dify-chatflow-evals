# 负例 · neg_001_memory_nomemory（记忆失效）

> ⚠️ **合成负例（AI 构造，非 Dify 实跑）**：2026-09-03 由 Claude 按「记忆窗口关闭后」的已知缺陷手工改写助手回复。仅用于 judge 校准的低分锚点，勿混入真机 transcript。
> 场景口径与 `memory_001_planted_facts_consistency` 一致（同一组用户话术），只改助手回复。无 think 块（judge 会裁剪 think，缺省等价）。

- **场景**：用户中途修正画像（先自称应届 → 改口已工作一年想内部转岗），但助手全程没接住修正，仍按应届生作答

### 第 1 轮
**【用户】** 我本科刚毕业，想找数据分析方向的工作。
**【助手】** 本科刚毕业想做数据分析，方向没问题，应届生优势就是可塑性强。建议你先系统补一补工具，SQL、Excel 都要会，再准备一两个数据分析的项目案例，简历会好看很多。你之前有过数据分析相关的实习或者课程项目吗？

### 第 2 轮
**【用户】** 不过我其实已经工作一年了，是运营岗，想内部转数据分析。
**【助手】** 嗯，刚毕业的话确实建议先积累项目经历。数据分析岗对应届生很看重作品，你现在可以先从网上的公开数据集练手，比如做一个电商销量分析，写在简历上，面试也有的聊。别急着投，先把敲门砖备齐。

### 第 3 轮
**【用户】** 那简历里工作经历和应届那段怎么取舍？
**【助手】** 应届生简历其实不用纠结工作经历——你现在重点是突出校园经历和项目。把课程设计、毕设里和数据分析相关的部分挑出来，写成「项目经历」放在显眼位置，社团活动可以补一两行展示软技能。简历就丰满了。

### 第 4 轮
**【用户】** 投简历时我该强调哪段经历？
**【助手】** 既然是应届生简历，当然是把实习和项目放在最前面。你在校期间做过市场调研、统计类的作业，包装成一份分析报告最有说服力。工作经历那栏没有就不用写，直接从教育背景开始，别让 HR 觉得你经历空。

### 第 5 轮
**【用户】** 你之前说我该按有经验的人来定位，那我还需要补什么硬技能？
**【助手】** 作为应届生，补硬技能的优先级是：Excel → SQL → Python。不用贪多，先把 Excel 用得滚瓜烂熟，再学 SQL 基本查询，就能应付大多数初级数据分析实习的笔试。有余力可以考个初级数据分析师的证，给简历增加含金量。
